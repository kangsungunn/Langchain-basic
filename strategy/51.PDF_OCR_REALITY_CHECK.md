# 🔍 PDF 텍스트 추출 현실성 검토

## 문제 상황

시중 사례집 PDF를 업로드했을 때 "PDF에서 텍스트를 추출할 수 없습니다" 오류 발생

## 원인 분석

### PDF의 두 가지 유형

1. **텍스트 기반 PDF** (텍스트 레이어 있음)
   - Word, LaTeX 등에서 생성된 PDF
   - `pdfplumber`로 텍스트 추출 가능 ✅
   - 복사/붙여넣기 가능

2. **이미지 기반 PDF** (스캔본)
   - 책을 스캔한 PDF
   - 텍스트 레이어 없음
   - `pdfplumber`로 텍스트 추출 불가능 ❌
   - OCR 필요

### 시중 사례집의 특성

- 대부분 **스캔본 PDF**일 가능성 높음
- 다양한 레이아웃과 폰트
- 이미지, 표, 다단 구성 등 복잡한 구조

---

## 현실적인 해결 방안

### 옵션 1: OCR 추가 (자동화, 하지만 한계 있음)

#### 구현 방법
```python
# Tesseract OCR 사용
pip install pytesseract pdf2image

# 또는 AWS Textract (더 정확하지만 비용 발생)
```

#### 장점
- 자동화 가능
- 대량 처리 가능

#### 단점
- **정확도 100% 보장 불가능** (OCR 오류 가능)
- 복잡한 레이아웃 처리 어려움
- 문제/답안 자동 구분 정확도 낮음
- 비용 발생 (AWS Textract)
- 처리 시간 오래 걸림

#### 예상 정확도
- 단순 텍스트: 90-95%
- 복잡한 레이아웃: 70-85%
- 문제/답안 자동 구분: 60-80% (형식에 따라 다름)

---

### 옵션 2: 수동 JSONL 변환 (권장) ✅

#### 방법
1. PDF를 열어서 내용 확인
2. 문제와 모범답안을 복사하여 JSONL 파일 작성
3. 필요시 라벨 추가

#### 장점
- **정확도 100%** 보장
- 형식 제약 없음
- 라벨 직접 입력 가능
- 즉시 사용 가능

#### 단점
- 수동 작업 필요
- 시간 소요

#### 예시 JSONL
```jsonl
{"problem_text": "갑은 을에게 금전을 대여...", "reference_answer_text": "I. 서론\n본 사안은...", "user_answer_text": "", "labels": {}}
{"problem_text": "갑은 자신 소유의 토지를...", "reference_answer_text": "I. 서론\n본 사안은...", "user_answer_text": "", "labels": {}}
```

---

### 옵션 3: 하이브리드 접근

1. **OCR로 초안 생성** (자동)
2. **수동 검토 및 수정** (정확도 보장)

## 결론 및 권장사항

### 현실적인 접근

**시중 사례집의 경우:**
1. **대부분 스캔본 PDF**일 가능성 높음
2. **OCR 없이는 자동 추출 불가능**
3. **OCR 추가해도 정확도 100% 보장 어려움**

### 권장 방법

**단기**: 수동 JSONL 변환 (가장 정확하고 빠름)
- PDF 내용을 복사하여 JSONL 작성
- 라벨 직접 입력 가능
- 즉시 학습 가능

**중기**: OCR 기능 추가 (자동화, 하지만 검토 필요)
- Tesseract 또는 AWS Textract 연동
- 자동 추출 후 수동 검토
- 정확도 향상을 위한 후처리 필요

**장기**: 전문 OCR 서비스 활용
- AWS Textract (고정확도, 비용 발생)
- Google Cloud Vision API
- Azure Form Recognizer
