# 🔗 KoELECTRA 파인튜닝 모델 통합

## 📋 개요

더미 데이터로 구조를 완성하고, 나중에 실제 데이터를 넣으면 자동으로 작동하도록 통합합니다.

**핵심 원칙**:
- 더미 데이터로 구조 완성
- 실제 데이터 준비되면 자동으로 사용
- 코드 변경 최소화

---

## 🎯 통합 전략

### 1. 모델 경로 자동 선택

**`KoELECTRALoader` 수정**:
- 파인튜닝된 모델이 있으면 자동으로 사용
- 없으면 베이스 모델 사용
- 환경 변수로 경로 지정 가능 (선택사항)

**우선순위**:
1. 환경 변수 `KOELECTRA_MODEL_PATH` (선택사항)
2. 파인튜닝된 모델: `artifacts/models/finetuned/koelectra-policy-rule`
3. 베이스 모델: `artifacts/models/base/koelectra-small-v3-discriminator`

### 2. 자동 감지 및 사용

**동작 방식**:
```python
# KoELECTRALoader 초기화 시
if 파인튜닝된_모델_존재:
    파인튜닝된_모델_사용()
else:
    베이스_모델_사용()
```

**장점**:
- 코드 변경 없음
- 실제 데이터로 학습하면 자동으로 파인튜닝된 모델 사용
- 더미 데이터로 학습한 모델도 자동으로 사용
