# PDF 파싱 및 라이브러리 가이드 (통합)

민사소송법 문제/답안 PDF를 텍스트·JSONL로 변환할 때 사용할 라이브러리 선택, 사용법, 성능, PowerShell 주의사항, 문제 해결을 한 문서로 정리한 가이드입니다.

---

## 1. 라이브러리 개요 및 비교

### 1.1 후보 라이브러리

| 라이브러리 | 라이선스 | 설치 | 상태 |
|-----------|----------|------|------|
| **pdfplumber** | MIT | `pip install pdfplumber` | 정확도·레이아웃 우선 |
| **PyPDF2** | BSD | `pip install PyPDF2` | 유지보수 중단 → **pypdf 이전 권장** |
| **pypdf** | BSD | `pip install pypdf` | PyPDF2 후속, **현재 권장** |

### 1.2 속도·기능 비교

**속도**

- pdfplumber: 기준(1x), 상대적으로 느림
- PyPDF2 / pypdf: 약 3~5배 빠름

**기능 (요약)**

| 기능 | pdfplumber | pypdf |
|------|-----------|-------|
| 기본 텍스트 추출 | 우수 | 양호 |
| 레이아웃·표·다단 | 우수 | 제한적 |
| 표 추출 | 우수 | 어려움 |
| 복잡한 PDF | 우수 | 제한적 |

**결론**

- **PyPDF2는 사용하지 말고 pypdf 사용** (유지보수·버그 수정·호환성 우수).
- 민사소송법 PDF처럼 **구조가 복잡할 수 있는 경우**: 정확도 우선이면 pdfplumber 유지, 속도도 필요하면 아래 “하이브리드” 참고.

---

## 2. 프로젝트별 권장 선택

### 2.1 민사소송법 문제/답안 PDF용

1. **1순위: pdfplumber 유지**
   - 복잡한 구조·표·다단 가능성, 정확한 추출이 중요할 때.
   - 단점: 느리지만, 변환을 한 번만 하면 되면 수용 가능.

2. **2순위: 하이브리드**
   - 먼저 pypdf로 시도 → 품질/실패 시 pdfplumber로 폴백.
   - `pdf_to_policy_rule_jsonl_hybrid.py` 등으로 구현 가능.

3. **3순위: pypdf만 사용**
   - PDF가 단순한 구조일 때만. 복잡한 PDF는 실패 가능성 있음.

### 2.2 텍스트 vs 복잡 레이아웃 vs 이미지

- **텍스트 위주 PDF**: pypdf 고속 스크립트 사용.
- **표·다단 등 복잡 레이아웃**: pdfplumber 사용.
- **이미지 기반 PDF(스캔)**: pypdf/pdfplumber만으로는 부족, OCR(Tesseract 등) 필요.

## 3. 설치 및 실행

### 3.1 pypdf 설치·확인

```bash
pip install pypdf
python -c "import pypdf; print(f'pypdf 버전: {pypdf.__version__}')"
```

### 3.2 고속(pypdf) 스크립트 실행 (Bash 예시)

```bash
# 단일 PDF
python training/orchestration/pdf_to_policy_rule_jsonl_fast.py \
    data/raw/civil_procedure/problems/57회.pdf

# 출력 경로 지정
python training/orchestration/pdf_to_policy_rule_jsonl_fast.py \
    data/raw/civil_procedure/problems/57회.pdf \
    --output training/data/policy_rule_classification/57회.jsonl
```

### 3.3 PowerShell에서 실행 (Windows)

PowerShell에서는 **백슬래시 `\`가 줄 연속 문자가 아님**. 아래 중 하나 사용.

**권장: 따옴표 + 한 줄**

```powershell
python training/orchestration/pdf_to_policy_rule_jsonl_fast.py "data/raw/civil_procedure/problems/57회.pdf"
```

**여러 줄: 백틱(`) 사용**

```powershell
python training/orchestration/pdf_to_policy_rule_jsonl_fast.py `
    "data/raw/civil_procedure/problems/57회.pdf" `
    --output "training/data/policy_rule_classification/57회.jsonl"
```

**잘못된 예 (에러 유발)**

```powershell
# ❌ PowerShell에서 \ 는 줄 연속이 아님
python ... \   data\raw\...\57회.pdf
# → FileNotFoundError: '\\' 등 발생 가능
```

한글/공백 경로는 **경로 전체를 따옴표로 감싸기**. 필요 시 절대 경로 사용.

## 5. 파싱 문제 진단 및 해결

### 5.1 증상: 추출 항목이 너무 적거나 내용이 깨짐

가능한 원인:

1. **문제/답안 구분 패턴이 실제 PDF 구조와 불일치**
   - 예: `【문제-1】`, `문항별 질문`, `모범답안`, `【해설】` 등 실제 표기를 확인해 패턴 수정.
2. **pypdf의 한계**
   - 복잡한 레이아웃에서 순서 뒤바뀜, 다단·표 인식 어려움.
3. **문제/답안 블록 분리 로직**
   - 패턴 매칭 실패 시 블록이 잘못 잘리거나 하나로 합쳐짐.

### 5.2 대응 순서

1. **PDF에서 텍스트가 나오는지 확인**
   - 페이지별로 추출한 raw 텍스트를 출력하는 디버그 스크립트나 소량 코드로 확인.
2. **패턴 확인·수정**
   - 실제 PDF에 나오는 제목·번호 형식에 맞게 정규식/키워드 수정.
3. **pdfplumber로 재시도**
   - `python training/orchestration/pdf_to_policy_rule_jsonl.py "경로/57회.pdf"`
   - 레이아웃이 복잡하면 pypdf 대신 pdfplumber가 유리.
4. **하이브리드 스크립트 사용**
   - `pdf_to_policy_rule_jsonl_hybrid.py` 등으로 pypdf 실패 시 자동으로 pdfplumber 폴백.

### 5.3 pypdf 설치·실행 오류

- Python 3.7 이상 확인: `python --version`
- 재설치: `pip install --upgrade pypdf`
- 경로·한글: 경로를 따옴표로 감싸고, 필요 시 UTF-8 설정 확인.
