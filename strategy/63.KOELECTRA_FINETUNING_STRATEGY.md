**현재 상태**:

- ✅ DecisionMaker 3단계 판단 구현 완료

### 1. 모델 성능 향상

- 모호한 경우의 판별 정확도 향상

## 📊 현재 구조 분석

### DecisionMaker 3단계 판단

```
1단계: 규칙 기반 사전 필터링 (빠른 판단)
  └─> RULE_BASED_ACTIONS 매칭 → "rule" 반환

2단계: 정책 기반 사전 필터링 (빠른 판단)
  └─> POLICY_BASED_ACTIONS 매칭 → "policy" 반환

3단계: KoELECTRA 모델 판단 (모호한 경우)
  └─> 프롬프트 구성 → KoELECTRA.predict() → "policy" 또는 "rule" 반환
```

### KoELECTRA 현재 사용 방식

**파일**: `app/core/ml/koelectra_loader.py`

**현재 모델 경로**:
- `artifacts/models/base/koelectra-small-v3-discriminator`
- 베이스 모델 (파인튜닝 전)

**입력 형식**:
```python
prompt = f"""
다음은 민사소송법 서술형 답안지 첨삭 시스템의 API 요청입니다.

**도메인**: {domain}
**액션**: {action}
**요청 요약**: {request_summary}

이 요청을 처리하기 위해:
1. ML 모델(EXAONE 등) 추론이 필요한가요?
2. 복잡한 비즈니스 로직이나 여러 도메인 간 협업이 필요한가요?
3. Star 토폴로지(Reasoning Hub)를 통한 중앙 집중식 처리가 필요한가요?

위 질문 중 하나라도 "예"라면 → **정책 기반 (policy)**
모두 "아니오"라면 → **규칙 기반 (rule)**

답변: [policy 또는 rule]
"""
```

**출력 형식**:
```python
{
    "strategy": "policy" | "rule",
    "confidence": float (0.0 ~ 1.0),
    "probabilities": {
        "rule": float,
        "policy": float
    }
}
```

## 📝 학습 데이터 준비

### 1. 데이터 수집

**수집 방법**:
1. 실제 API 요청 로그 수집
2. 도메인/액션 조합별 샘플 수집
3. 정책/규칙 라벨링

**수집 대상**:
- 도메인: `reasoning`, `training`, `submission`, `reference`, `feedback`
- 액션: 각 도메인별 모든 액션
- 요청 데이터: 실제 요청 본문 또는 요약

### 2. 데이터 형식

**JSONL 형식**:
```jsonl
{"text": "도메인: reasoning, 액션: comprehensive_analysis, 요청 요약: 사용자 답안 종합 분석 요청", "label": 1}
{"text": "도메인: training, 액션: create_training_data, 요청 요약: 학습 데이터 생성 요청", "label": 0}
{"text": "도메인: submission, 액션: create_text_answer, 요청 요약: 텍스트 답안 생성 요청", "label": 0}
```

**라벨 매핑**:
- `0`: rule (규칙 기반)
- `1`: policy (정책 기반)

### 3. 데이터 분할

**권장 비율**:
- 학습 데이터: 80%
- 검증 데이터: 10%
- 테스트 데이터: 10%

**최소 데이터 수**:
- 각 클래스당 최소 100개 이상
- 총 최소 200개 이상 (권장: 500개 이상)

## 🔧 파인튜닝 구현

### 1. 학습 스크립트 생성

**파일**: `training/orchestration/train_koelectra_policy_rule.py`

**기능**:
- JSONL 데이터 로드
- KoELECTRA 모델 로드
- 분류 학습 (2-class classification)
- 평가 메트릭 (Accuracy, F1, Precision, Recall)
- 모델 저장

### 2. 학습 설정

**모델**: `monologg/koelectra-small-v3-discriminator`

**학습 방식**:
- **Full Finetuning** (권장): 전체 모델 파라미터 학습
- **LoRA** (선택): 메모리 절약이 필요한 경우

**하이퍼파라미터**:
```python
{
    "learning_rate": 2e-5,
    "batch_size": 16,
    "num_epochs": 3-5,
    "max_length": 512,
    "warmup_steps": 100,
    "weight_decay": 0.01
}
```

### 3. 평가 메트릭

**주요 메트릭**:
- Accuracy (정확도)
- F1 Score (F1 점수)
- Precision (정밀도)
- Recall (재현율)

**목표 성능**:
- Accuracy: 95% 이상
- F1 Score: 0.95 이상
