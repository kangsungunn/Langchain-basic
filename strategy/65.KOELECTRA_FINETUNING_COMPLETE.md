## 🎯 학습 파이프라인 테스트 결과

### 더미 데이터로 학습 실행 완료
- **에폭**: 1 에폭 (테스트용)
- **배치 크기**: 8
- **학습 시간**: ~3.8초

### 평가 결과 (1 에폭, 더미 데이터)
- **Accuracy**: 57.89%
- **F1 Score**: 0.4246
- **Precision**: 0.3352
- **Recall**: 0.5789

**참고**:
- 1 에폭만 학습했고 더미 데이터가 적어서 성능이 낮은 것은 정상입니다.
- 실제 데이터로 더 많은 에폭(3-5 에폭)을 학습하면 성능이 향상될 것입니다.

### 모델 저장 위치
- `artifacts/models/finetuned/koelectra-policy-rule/`

## 🔧 사용 방법

### 더미 데이터 생성 (임시)
```bash
python training/orchestration/data_factory.py
```

### 실제 데이터로 학습
```bash
python training/orchestration/train_koelectra_policy_rule.py \
    --data-dir training/data/policy_rule_classification \
    --output-dir artifacts/models/finetuned/koelectra-policy-rule \
    --num-epochs 5 \
    --batch-size 16
```

### 데이터 확인
```bash
python training/orchestration/check_data.py
```
