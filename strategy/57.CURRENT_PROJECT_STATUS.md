## 🔧 알려진 이슈 (기능에는 영향 없음)

### 1. Unicode 인코딩 경고 (Windows)
- **문제**: 로그 출력 시 이모지(✅, ❌, 🎯 등)가 `UnicodeEncodeError` 발생
- **원인**: Windows 콘솔의 cp949 인코딩
- **상태**: 기능에는 영향 없음 (HTTP 응답은 정상)
- **해결 시도**: `app/core/utils/logger.py`에 UTF-8 인코딩 설정 추가 (부분적 해결)

### 2. 로거 이모지 출력
- **위치**: `app/core/orchestration/` 내 모든 파일
- **영향**: 로그 출력 시 경고 발생하지만 기능 정상
- **권장**: 나중에 이모지 제거 또는 더 강력한 인코딩 처리
