## 🔧 문제 해결

### 문제 1: 파인튜닝된 모델이 감지되지 않음
**원인**: 모델 파일이 없거나 경로가 잘못됨
**해결**:
1. `artifacts/models/finetuned/koelectra-policy-rule/` 디렉토리 확인
2. `model.safetensors` 또는 `pytorch_model.bin` 파일 존재 확인
3. `config.json` 파일 존재 확인

### 문제 2: 모델 로드 실패
**원인**: 모델 파일 손상 또는 경로 오류
**해결**:
1. 모델 파일 무결성 확인
2. 학습 스크립트 재실행
3. 베이스 모델로 폴백 확인

### 문제 3: 성능 개선이 없음
**원인**: 더미 데이터로 학습했거나 에폭 수 부족
**해결**:
1. 실제 데이터로 재학습 (Phase 2)
2. 에폭 수 증가 (5-10 에폭)
3. 하이퍼파라미터 튜닝 (Phase 3)
