# 📄 PDF → JSONL 학습 파이프라인 전략

## 🎯 목표

사용자가 PDF 파일을 업로드하면 자동으로 JSONL 형식으로 변환하여 학습 데이터로 사용하고, 모델 학습을 자동으로 시작하는 전체 파이프라인 구축

---

## 📊 현재 구현 상태

### ✅ 구현 완료된 부분

#### 1. **JSONL 업로드 및 파싱** ✅
- **위치**: `frontend/src/app/v1/admin/training/route.ts`
- **기능**:
  - JSONL 파일 업로드
  - 각 줄 파싱 및 검증
  - 필수 필드 확인 (`problem_text`, `reference_answer_text`, `user_answer_text`)
- **상태**: 완전 구현됨

#### 2. **학습 데이터 생성 API** ✅
- **위치**: `app/api/v1/training.py` → `POST /api/v1/training/data`
- **기능**:
  - 학습 데이터를 DB에 저장 (`TrainingData` 테이블)
  - 자동 학습 트리거 (데이터 10개 이상 시 자동 시작)
- **상태**: 완전 구현됨

#### 3. **학습 실행 파이프라인** ✅
- **위치**: `app/domain/training/services.py` → `TrainingOrchestrator`
- **기능**:
  - 학습 데이터를 JSONL 파일로 변환 (`data/processed/civil_law/train_{job_id}.jsonl`)
  - Train/Val 분할 (80/20)
  - 실제 모델 학습 실행 (`training.examination.civil_law.train_simple.train_model`)
  - 학습 진행 상황 모니터링
- **상태**: 완전 구현됨

#### 4. **학습 데이터 스키마** ✅
- **위치**: `app/domain/training/schemas.py` → `TrainingDataCreate`
- **필수 필드**:
  ```python
  {
    "problem_text": str,
    "reference_answer_text": str,
    "user_answer_text": str,
    "labels": dict,  # {"issue_coverage": 0.75, "logic_score": 0.8}
    "problem_id": Optional[str],
    "reference_answer_id": Optional[str],
    "user_answer_id": Optional[str]
  }
  ```
- **상태**: 완전 구현됨

## 🔄 전체 파이프라인 흐름

### 현재 가능한 방법 (수동)

```
[1] PDF 파일 준비
    ↓
[2] 수동으로 PDF 내용을 읽어서 JSONL 형식으로 변환
    {
      "problem_text": "...",
      "reference_answer_text": "...",
      "user_answer_text": "...",
      "labels": {...}
    }
    ↓
[3] 관리자 화면에서 JSONL 파일 업로드
    (frontend/src/app/v1/admin/page.tsx)
    ↓
[4] 프론트엔드 API Route가 JSONL 파싱
    (frontend/src/app/v1/admin/training/route.ts)
    ↓
[5] 각 줄을 개별 학습 데이터로 백엔드 API 호출
    POST /api/v1/training/data
    ↓
[6] TrainingDataService가 DB에 저장
    (app/domain/training/services.py)
    ↓
[7] 자동 학습 트리거 (데이터 10개 이상)
    TrainingOrchestrator.check_auto_training_trigger()
    ↓
[8] 학습 시작
    TrainingOrchestrator.start_training()
    ↓
[9] 학습 데이터를 JSONL로 변환
    data/processed/civil_law/train_{job_id}.jsonl
    ↓
[10] 실제 모델 학습 실행
    training.examination.civil_law.train_simple.train_model()
    ↓
[11] 학습 완료 후 모델 저장
    artifacts/models/finetuned/legal/checkpoint_{job_id}/
```

### 목표 방법 (자동)

```
[1] PDF 파일 업로드
    관리자 화면에서 PDF 업로드
    ↓
[2] PDF 파싱 서비스 (구현 필요)
    - PDF 텍스트 추출
    - 문제/모범답안/사용자답안 분리
    - 구조화된 데이터 생성
    ↓
[3] JSONL 변환 (구현 필요)
    - 파싱된 데이터를 JSONL 형식으로 변환
    - 각 문제별로 한 줄씩 생성
    ↓
[4] 학습 데이터 생성 (이미 구현됨)
    POST /api/v1/training/data
    ↓
[5] 자동 학습 시작 (이미 구현됨)
    TrainingOrchestrator.start_training()
    ↓
[6] 학습 실행 (이미 구현됨)
    train_model()
```

### Phase 1: PDF 파싱 서비스 구현

#### 1.1 PDF 텍스트 추출 라이브러리 선택

**옵션 1: PyPDF2** (간단, 빠름)
```python
pip install PyPDF2
```
- 장점: 가볍고 빠름
- 단점: 복잡한 레이아웃 처리 어려움

**옵션 2: pdfplumber** (권장)
```python
pip install pdfplumber
```
- 장점: 표, 레이아웃 분석 우수
- 단점: PyPDF2보다 느림

**옵션 3: AWS Textract** (강사님 언급)
- 장점: OCR, 구조 인식 우수
- 단점: AWS 의존성, 비용

**권장**: pdfplumber로 시작, 필요시 AWS Textract로 확장
