# Star Topology Hybrid Architecture - 프로젝트 요약

## 🎯 프로젝트 개요

**EXAONE Hub Router (Star)를 중심으로 한 중앙 집권화 멀티 브랜치 아키텍처**

- **Gateway**: 규칙 기반 + ML 보조 (70-90% 빠른 처리)
- **Hub Router (Star)**: 중앙 통제, 브랜치 관리, 최종 액션 결정, DB 독점
- **Branches**: 순수 작업 수행자 (스팸, 환불, 감성 분석 등)

---

## 📦 구현 완료 현황

### ✅ Phase 1: Gateway (완료)

**구현 완료**:
- ✅ `HybridGateway`: 규칙 + ML 통합
- ✅ `RuleEngine`: 계층적 규칙 실행 (Security → Policy → Routing)
- ✅ `MLAssistant`: KoELECTRA 기반 모호한 입력 분류
- ✅ `SecurityRules`: 입력 검증, 인젝션 감지, Rate Limiting
- ✅ `PolicyRules`: 금칙어, 부적절한 콘텐츠, URL 패턴
- ✅ `RoutingRules`: 키워드/길이/패턴 기반 라우팅
- ✅ 테스트: `test_hybrid_gateway.py`

**성능**:
- 규칙 기반: 1-5ms (70-90% 처리)
- ML 보조: 50-100ms (10-30% 처리)

---

### ✅ Phase 2: Hub Router (완료)

**구현 완료**:
- ✅ `HubRouter`: 중앙 집권화 브랜치 관리
- ✅ `BranchRegistry`: 브랜치 등록/해제/조회, 메트릭 수집
- ✅ `BranchHealthChecker`: 백그라운드 헬스 체크 (30초 간격)
- ✅ `OntologyManager`: 태스크 타입, 라벨 스키마, 정책 관리
- ✅ 최종 액션 결정 로직 (Star의 권한)
- ✅ 테스트: `test_hub_router.py`

**기본 브랜치**:
- ✅ `spam_agent`: 스팸 분석 (active)
- ✅ `default_agent`: 폴백용 (active)
- ⏳ `refund_agent`: 환불 처리 (inactive, 향후 구현)

**정의된 태스크**:
- 📧 `spam`: 스팸 분류 (auto_block_threshold: 3, quarantine_threshold: 1)
- 💳 `refund`: 환불 처리 (auto_approve_threshold: 0.9)
- 😊 `sentiment`: 감성 분석 (negative_alert_threshold: 0.8)

## 🎯 핵심 원칙 (Star Topology)

### 1. 중앙 집권화 (Centralization)

| 주체 | 권한 | 금지 |
|------|------|------|
| **Hub Router (Star)** | ✅ 모든 브랜치 관리<br>✅ 온톨로지/정책 독점<br>✅ 최종 액션 결정<br>✅ DB 접근 독점 | - |
| **Branch** | ✅ 분석/처리 수행<br>✅ 권장 액션 제안 | ❌ DB 접근<br>❌ 최종 결정<br>❌ 다른 브랜치 호출 |
| **Gateway** | ✅ 1차 필터링<br>✅ 빠른 차단 | ❌ DB 접근<br>❌ 브랜치 직접 호출 |

### 2. 역할 분리 (Separation of Concerns)

```
Gateway (입구)
   └─> 70-90% 빠른 처리 (규칙 기반)
   └─> 10-30% ML 보조 (모호한 케이스)

Hub Router (Star, 중앙 통제)
   └─> 브랜치 선택 및 관리
   └─> 온톨로지/정책 적용
   └─> 최종 액션 결정
   └─> DB 저장

Branch (작업 수행자)
   └─> 순수 분석/처리
   └─> BranchResult 반환
   └─> DB 접근 금지!
```

### 3. 데이터 흐름 (Unidirectional Flow)

```
User Input → Gateway → Hub Router → Branch → Hub Router → User Response
                                              ↓
                                           DB 저장 (Star만!)
```

| 구간 | 지연 시간 | 처리 비율 | 비고 |

| **전체 (평균)** | 20-50ms | - | 규칙 비율에 따라 |
