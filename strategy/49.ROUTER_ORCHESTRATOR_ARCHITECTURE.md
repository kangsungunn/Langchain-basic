## 1. 강사님 아키텍처 요구사항

### 1.1 전체 흐름

```
┌──────────────┐
│  프론트엔드   │
│  (Next.js)   │
└──────┬───────┘
       │
       │ HTTP 요청
       ▼
┌──────────────┐
│   라우터     │  ← 프론트와 백엔드 연결
│  (Router)    │
└──────┬───────┘
       │
       │ 요청 전달
       ▼
┌──────────────┐
│ 오케스트레이터│  ← 정책/규칙 판단
│(Orchestrator)│
└──────┬───────┘
       │
       │ 정책/규칙 기반 판단
       ▼
   ┌───┴───┐
   │       │
   ▼       ▼
┌─────┐ ┌──────────┐
│Star │ │일반 서비스│
│토폴로지│ │ (Direct) │
└─────┘ └──────────┘
```

### 1.2 핵심 요구사항

1. **라우터 (Router)**
   - 프론트엔드와 백엔드 연결
   - 요청을 오케스트레이터로 전달

2. **오케스트레이터 (Orchestrator)**
   - 정책 기반 vs 규칙 기반 판단
   - Star 토폴로지로 갈지, 일반 서비스로 갈지 결정

3. **라우팅 결정**
   - **정책 기반**: 복잡한 비즈니스 로직 → Star 토폴로지
   - **규칙 기반**: 단순 CRUD → 일반 서비스 (Direct)

## 2. 현재 구조 분석

### 2.1 현재 아키텍처

```
┌─────────────────────────────────────────────────────────┐
│              현재 구조 (직접 연결)                       │
└─────────────────────────────────────────────────────────┘

[프론트엔드]
frontend/src/app/
├── api/v1/
│   ├── reference/route.ts    (비어있음)
│   ├── submission/route.ts   (비어있음)
│   ├── reasoning/route.ts    (비어있음)
│   └── feedback/route.ts     (비어있음)
└── page.tsx

[백엔드]
app/api/              # Router Layer (라우터 레이어) ⭐
├── main.py          # FastAPI 앱 진입점
└── v1/              # API v1 (현재 버전)
    ├── reference.py      → ReferenceService 직접 호출
    ├── submission.py    → SubmissionService 직접 호출
    ├── reasoning.py     → ReasoningEngine 직접 호출
    ├── feedback.py      → FeedbackGenerator 직접 호출
    └── training.py      → TrainingOrchestrator 직접 호출
# 향후 v2/, v3/ 등 버전별 폴더 추가 가능

[도메인 서비스]
app/domain/
├── reference/services.py
├── submission/services.py
├── reasoning/services.py
├── feedback/services.py
└── training/services.py

[오케스트레이션]
app/core/orchestration/
├── base_orchestrator.py    (비어있음)
└── workflow_manager.py     (비어있음)
```

### 2.2 현재 구조의 문제점

1. **라우터 레이어 부재**
   - 프론트엔드 API Routes가 비어있음
   - 백엔드 라우터가 직접 서비스 호출

2. **오케스트레이터 레이어 부재**
   - 파일은 있지만 비어있음
   - 정책/규칙 판단 로직 없음

3. **Star 토폴로지 부재**
   - 이전에 있던 Star 토폴로지 코드가 삭제됨
   - 현재는 일반 서비스만 존재

4. **라우팅 결정 로직 부재**
   - 모든 요청이 직접 서비스로 전달
   - 정책/규칙 기반 분기 없음

## 3. 적용 가능성 검증

### 3.1 ✅ 적용 가능한 부분

1. **프론트엔드 → 라우터**
   - Next.js API Routes 활용 가능
   - `frontend/src/app/api/v1/` 구조 이미 존재

2. **라우터 → 오케스트레이터**
   - `app/api/` (라우터 레이어)를 중간 레이어로 활용 가능
   - `app/api/v1/` 라우터를 오케스트레이터로 연결

3. **오케스트레이터 구현**
   - `app/core/orchestration/` 폴더 이미 존재
   - 기존 도메인 서비스 구조 유지 가능

4. **Star 토폴로지 재구현**
   - Reasoning Domain이 이미 HUB 역할
   - Star 토폴로지 패턴 적용 가능

### 3.2 ⚠️ 추가 구현 필요

1. **라우터 레이어 구현**
   - 프론트엔드 API Routes 구현
   - 백엔드 라우터를 오케스트레이터로 연결

2. **오케스트레이터 구현**
   - 정책/규칙 판단 로직
   - Star vs 일반 서비스 라우팅

3. **Star 토폴로지 재구현**
   - Reasoning Hub를 Star Node로 확장
   - 브랜치 라우팅 로직

4. **정책/규칙 엔진**
   - 정책 기반 판단 로직
   - 규칙 기반 판단 로직

### 4.2 구현 단계

#### Phase 1: 라우터 레이어 구현

**1-1. 프론트엔드 라우터 (Next.js API Routes)**

```typescript
// frontend/src/app/api/v1/reasoning/route.ts
import { NextRequest, NextResponse } from 'next/server'

const BACKEND_URL = process.env.BACKEND_URL || 'http://localhost:8000'

export async function POST(request: NextRequest) {
  try {
    const body = await request.json()

    // 백엔드로 프록시
    const response = await fetch(`${BACKEND_URL}/api/v1/reasoning/analyze/issues`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(body)
    })

    const data = await response.json()
    return NextResponse.json(data)
  } catch (error) {
    return NextResponse.json(
      { error: 'Internal Server Error' },
      { status: 500 }
    )
  }
}
```

**1-2. 백엔드 라우터 수정**

```python
from app.core.orchestration.workflow_manager import WorkflowManager

@router.post("/analyze/issues", response_model=AnalysisResponse)
```

#### Phase 2: 오케스트레이터 구현

**2-1. 정책/규칙 판단 로직**

```python
# app/core/orchestration/workflow_manager.py
from enum import Enum
from typing import Dict, Any, Optional

class RoutingStrategy(str, Enum):
    """라우팅 전략"""
    STAR_TOPOLOGY = "star"      # Star 토폴로지 (정책 기반)
    DIRECT_SERVICE = "direct"   # 일반 서비스 (규칙 기반)

class WorkflowManager:
    """중앙 오케스트레이터"""

    def __init__(self, session: AsyncSession):
        self.session = session
        self.policy_engine = PolicyEngine()
        self.rule_engine = RuleEngine()

    async def process_request(
        self,
        domain: str,
        action: str,
        request: Any
    ) -> Any:
        """
        요청 처리 (정책/규칙 판단 후 라우팅)
        """
        # [1] 정책/규칙 판단
        strategy = await self._determine_routing_strategy(domain, action, request)

        # [2] 라우팅 실행
        if strategy == RoutingStrategy.STAR_TOPOLOGY:
            return await self._route_to_star(domain, action, request)
        else:
            return await self._route_to_direct_service(domain, action, request)

    async def _determine_routing_strategy(
        self,
        domain: str,
        action: str,
        request: Any
    ) -> RoutingStrategy:
        """
        정책/규칙 기반 라우팅 전략 결정
        """
        # 규칙 기반 판단 (단순 CRUD)
        if self.rule_engine.is_simple_crud(domain, action):
            return RoutingStrategy.DIRECT_SERVICE

        # 정책 기반 판단 (복잡한 비즈니스 로직)
        if self.policy_engine.requires_complex_processing(domain, action, request):
            return RoutingStrategy.STAR_TOPOLOGY

        # 기본값: Star 토폴로지 (안전한 선택)
        return RoutingStrategy.STAR_TOPOLOGY

    async def _route_to_star(
        self,
        domain: str,
        action: str,
        request: Any
    ) -> Any:
        """
        Star 토폴로지로 라우팅
        """
        from app.domain.reasoning.orchestrators.reasoning_hub import ReasoningHub

        hub = ReasoningHub(self.session)
        return await hub.process(domain, action, request)

    async def _route_to_direct_service(
        self,
        domain: str,
        action: str,
        request: Any
    ) -> Any:
        """
        일반 서비스로 직접 라우팅
        """
        # 도메인별 서비스 매핑
        service_map = {
            "reference": ReferenceService,
            "submission": SubmissionService,
            "feedback": FeedbackGenerator,
            "training": TrainingOrchestrator
        }

        service_class = service_map.get(domain)
        if not service_class:
            raise ValueError(f"Unknown domain: {domain}")

        service = service_class(self.session)
        method = getattr(service, action, None)
        if not method:
            raise ValueError(f"Unknown action: {action}")

        return await method(request)
```

**2-2. 정책 엔진**

```python
# app/core/orchestration/policy_engine.py
class PolicyEngine:
    """정책 기반 판단 엔진"""

    def requires_complex_processing(
        self,
        domain: str,
        action: str,
        request: Any
    ) -> bool:
        """
        복잡한 처리 필요 여부 판단
        """
        # 정책 기반 판단 규칙
        complex_actions = {
            "reasoning": ["analyze_issues", "evaluate_logic", "review_expression", "comprehensive_analysis"],
            "feedback": ["generate_from_reasoning"],
            "training": ["start_training", "auto_feedback"]
        }

        return action in complex_actions.get(domain, [])
```

**2-3. 규칙 엔진**

```python
# app/core/orchestration/rule_engine.py
class RuleEngine:
    """규칙 기반 판단 엔진"""

    def is_simple_crud(
        self,
        domain: str,
        action: str
    ) -> bool:
        """
        단순 CRUD 작업 여부 판단
        """
        # 규칙 기반 판단: 단순 CRUD는 직접 서비스로
        simple_actions = ["create", "read", "update", "delete", "list"]

        return action in simple_actions
```

#### Phase 3: Star 토폴로지 재구현

**3-1. Reasoning Hub 확장**

```python
# app/domain/reasoning/orchestrators/reasoning_hub.py
class ReasoningHub:
    """Star 토폴로지 중앙 허브"""

    async def process(
        self,
        domain: str,
        action: str,
        request: Any
    ) -> Any:
        """
        Star 토폴로지 처리
        """
        # [1] 요청 분석
        context = await self._analyze_request(domain, action, request)

        # [2] 브랜치 선택 (필요시)
        branch = await self._select_branch(context)

        # [3] 처리 실행
        if branch:
            return await branch.process(context)
        else:
            return await self._process_directly(context)

    async def _process_directly(self, context: Dict) -> Any:
        """
        직접 처리 (EXAONE 모델 사용)
        """
        from app.domain.reasoning.services import ReasoningEngine

        engine = ReasoningEngine(self.session)

        if context["action"] == "analyze_issues":
            return await engine.analyze_issues(...)
        elif context["action"] == "evaluate_logic":
            return await engine.evaluate_logic(...)
        # ...
```
