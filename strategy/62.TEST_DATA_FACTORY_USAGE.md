# 📝 테스트 데이터 팩토리 사용 가이드

## 📋 개요

`app/core/utils/test_data_factory.py`는 테스트 및 개발 환경에서 사용할 더미 데이터를 생성하는 공통 유틸리티입니다.

**중요**: 실제 프로덕션 코드에서는 사용자가 명시적으로 데이터를 제공해야 합니다. 이 유틸리티는 테스트 및 개발 환경에서만 사용됩니다.

---

## 🎯 사용 목적

1. **테스트 환경**: 테스트 스크립트에서 실제 데이터 기준 코드를 사용하여 더미 데이터 생성
2. **개발 환경**: 개발 중 빠른 테스트를 위한 더미 데이터 생성
3. **실제 데이터 기준**: 실제 데이터 기준으로 작성된 코드를 재사용

---

## 📦 제공 함수

### 1. `create_test_data_for_analysis()`

**목적**: 분석을 위한 테스트 데이터 생성 (Problem, ReferenceAnswer, UserAnswer)

**사용 예시**:
```python
from app.core.utils.test_data_factory import create_test_data_for_analysis

async for session in get_session():
    # 더미 데이터 생성 (실제 데이터 기준 코드 사용)
    user_answer_id, reference_answer_id, problem_id = await create_test_data_for_analysis(session)

    # 생성된 ID로 분석 요청
    request = ComprehensiveAnalysisRequest(
        user_answer_id=user_answer_id,
        reference_answer_id=reference_answer_id,
        problem_id=problem_id,
        save_result=False
    )
```

**실제 데이터 기준 코드 사용**:
- `ProblemService.create_problem()` - 실제 서비스 코드
- `ReferenceAnswerService.create_answer()` - 실제 서비스 코드
- `UserAnswerService.create_text_answer()` - 실제 서비스 코드

---

### 2. `create_test_training_data()`

**목적**: 학습 데이터 생성을 위한 테스트 데이터 생성

**사용 예시**:
```python
from app.core.utils.test_data_factory import create_test_training_data

async for session in get_session():
    # 더미 데이터 생성
    user_answer_id, reference_answer_id, problem_id = await create_test_training_data(session)
```

## ✅ 핵심 원칙

### 1. 실제 데이터 기준 코드 유지

- **테스트 데이터 팩토리**: 실제 서비스 코드(`ProblemService`, `ReferenceAnswerService`, `UserAnswerService`)를 사용
- **실제 API/서비스**: 사용자가 제공한 ID를 그대로 사용 (DB에서 조회)
- **코드 일관성**: 테스트와 실제 코드가 동일한 로직 사용

### 2. 프로덕션 코드는 변경 없음

- **실제 API**: 사용자가 명시적으로 데이터를 제공해야 함
- **자동 생성 없음**: 프로덕션에서는 더미 데이터를 자동 생성하지 않음
- **에러 처리**: 데이터가 없으면 명확한 에러 메시지 반환

### 3. 테스트/개발 환경에서만 사용

- **테스트 스크립트**: `test_langgraph_orchestrator.py` 등에서 사용
- **개발 환경**: 개발 중 빠른 테스트를 위해 사용
- **프로덕션**: 사용하지 않음

## 🔍 코드 흐름 비교

### 테스트 환경
```
테스트 스크립트
  └─> create_test_data_for_analysis() (더미 데이터 생성)
      └─> ProblemService.create_problem() (실제 서비스 코드)
      └─> ReferenceAnswerService.create_answer() (실제 서비스 코드)
      └─> UserAnswerService.create_text_answer() (실제 서비스 코드)
  └─> WorkflowManager.process_request() (실제 오케스트레이터 코드)
      └─> ReasoningEngine.comprehensive_analysis() (실제 서비스 코드)
          └─> UserAnswerRepository.get_by_id() (실제 DB 조회)
```

### 프로덕션 환경
```
API 요청
  └─> WorkflowManager.process_request() (실제 오케스트레이터 코드)
      └─> ReasoningEngine.comprehensive_analysis() (실제 서비스 코드)
          └─> UserAnswerRepository.get_by_id() (실제 DB 조회)
              └─> 데이터 없으면 에러 반환
```

**차이점**: 테스트 환경에서는 더미 데이터를 먼저 생성하지만, 프로덕션에서는 사용자가 제공한 ID를 그대로 사용합니다.
