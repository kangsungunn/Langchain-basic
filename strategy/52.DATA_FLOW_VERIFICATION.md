# 🔍 학습 데이터 업로드 데이터 흐름 검증 가이드

## 📊 전체 데이터 흐름

```
[1] 프론트엔드 화면
    frontend/src/app/v1/admin/page.tsx
    ↓ 사용자가 "학습 데이터셋 업로드" 버튼 클릭
    ↓ handleSubmit() 함수 실행
    ↓ POST /v1/admin/training (FormData)

[2] 프론트엔드 API Route
    frontend/src/app/v1/admin/training/route.ts
    ↓ JSONL 파일 파싱 및 검증
    ↓ 각 줄을 개별 학습 데이터로 변환
    ↓ 백엔드로 각 데이터 전송
    ↓ POST http://localhost:8000/api/v1/training/data (JSON)

[3] 백엔드 API 라우터
    app/api/v1/training.py
    ↓ POST /api/v1/training/data 엔드포인트
    ↓ TrainingDataCreate 스키마 검증
    ↓ 로깅: 받은 데이터 출력
    ↓ TrainingDataService.create() 호출

[4] 학습 데이터 서비스
    app/domain/training/services.py
    ↓ TrainingData 생성 및 DB 저장
    ↓ 자동 학습 트리거 확인
    ↓ (조건 충족 시) 학습 시작
```

---

## ✅ 구현 상태

### 이미 구현되어 있음

1. **프론트엔드 업로드 버튼** ✅
   - 위치: `frontend/src/app/v1/admin/page.tsx`
   - 함수: `handleSubmit()`
   - 엔드포인트: `/v1/admin/training`

2. **프론트엔드 API Route** ✅
   - 위치: `frontend/src/app/v1/admin/training/route.ts`
   - 기능: JSONL 파싱, 백엔드로 전송

3. **백엔드 API 엔드포인트** ✅
   - 위치: `app/api/v1/training.py`
   - 엔드포인트: `POST /api/v1/training/data`
   - 라우터 등록: `app/main.py`에서 `training.router` 등록됨

## 🧪 테스트 방법

### Step 1: 백엔드 서버 실행

```bash
# 프로젝트 루트에서
python -m uvicorn app.main:app --reload
```

### Step 2: 프론트엔드 서버 실행

```bash
# frontend 폴더에서
npm run dev
```

### Step 3: 브라우저 개발자 도구 열기

- F12 또는 우클릭 → 검사
- Console 탭 열기

### Step 4: JSONL 파일 업로드

1. 관리자 화면 접속: `http://localhost:3000/v1/admin`
2. JSONL 파일 선택
3. "학습 데이터셋 업로드" 버튼 클릭
4. 브라우저 콘솔과 백엔드 터미널에서 로그 확인
