**수동으로 JSONL 파일 작성**:

**라벨**:
- `0`: 정책 기반 (policy)

## 📝 Step 3: 데이터 분할

### 권장 비율
- 학습: 70-80%
- 검증: 10-15%
- 테스트: 10-15%

### 분할 스크립트

**수동 분할**:
```python
# 예시: collected_logs.jsonl을 train/val/test로 분할
import json
from pathlib import Path

data_file = Path("training/data/collected_logs/collected_logs.jsonl")
train_file = Path("training/data/policy_rule_classification/train.jsonl")
val_file = Path("training/data/policy_rule_classification/val.jsonl")
test_file = Path("training/data/policy_rule_classification/test.jsonl")

# 데이터 로드
with open(data_file, 'r', encoding='utf-8') as f:
    data = [json.loads(line) for line in f if line.strip()]

# 분할 (70/15/15)
train_size = int(len(data) * 0.7)
val_size = int(len(data) * 0.15)

train_data = data[:train_size]
val_data = data[train_size:train_size+val_size]
test_data = data[train_size+val_size:]

# 저장
for file, data_split in [(train_file, train_data), (val_file, val_data), (test_file, test_data)]:
    with open(file, 'w', encoding='utf-8') as f:
        for item in data_split:
            f.write(json.dumps(item, ensure_ascii=False) + "\n")
```

## 📝 Step 5: 실제 데이터로 학습

### 학습 실행

```bash
python training/orchestration/train_koelectra_policy_rule.py \
    --data-dir training/data/policy_rule_classification \
    --output-dir artifacts/models/finetuned/koelectra-policy-rule \
    --num-epochs 5 \
    --batch-size 16
```

### 하이퍼파라미터 조정

**데이터 양에 따른 조정**:
- 500개 미만: 에폭 3-5, 학습률 2e-5
- 500-1000개: 에폭 5-7, 학습률 2e-5
- 1000개 이상: 에폭 7-10, 학습률 1e-5

**LoRA 사용 (선택사항)**:
```bash

    --data-dir training/data/policy_rule_classification \
```

**해결**:
- 데이터 증강
- 클래스 가중치 조정
- 더 많은 데이터 수집

### 문제 3: 오버피팅 발생
**해결**:
- 에폭 수 감소
- 학습률 낮추기
