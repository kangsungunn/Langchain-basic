# Core → Domain Migration 완료

> core/orchestration과 core/mcp를 domain으로 이동 완료.

---

## 완료된 작업

### 1. DecisionMaker 이동
- **이전**: `app/core/orchestration/decision_maker.py`
- **이후**: `app/domain/v1/minso/hub/decision_maker.py`
- **변경사항**: `determine_strategy()` → `decide()` 메서드명 변경

### 2. MinsoHub 생성
- **위치**: `app/domain/v1/minso/hub/orchestrators/minso_hub.py`
- **기능**:
  - DecisionMaker로 정책/규칙 자동 판단
  - 정책 → ReasoningHub로 라우팅
  - 규칙 → 서비스 직접 호출 (RuleStrategy 로직 통합)

### 3. MCP 코드 이동
- **이전**: `app/core/mcp/`
- **이후**: `app/domain/v1/minso/hub/mcp_central/`
- **파일**: protocol.py, message.py, transport.py, __init__.py

### 4. database.py 호환성 레이어
- **위치**: `app/core/database.py`
- **역할**: `from app.core.database import ...` 형태의 import 호환성 유지

### 5. API import 변경
- **이전**: `from app.core.orchestration import WorkflowManager`
- **이후**: `from app.domain.v1.minso.hub.orchestrators import MinsoHub`
- **변경 파일**:
  - `app/api/v1/minso/reasoning.py`
  - `app/api/v1/minso/feedback.py`
  - `app/api/v1/minso/submission.py`
  - `app/api/v1/minso/training.py`

### 6. 테스트/스크립트 import 변경
- **DecisionMaker**: `app.domain.v1.minso.hub.decision_maker`
- **MinsoHub**: `app.domain.v1.minso.hub.orchestrators`
- **MCP**: `app.domain.v1.minso.hub.mcp_central`
- **변경 파일**:
  - `test_langgraph_orchestrator.py`
  - `tests/test_orchestrator.py`
  - `test_phase0.py`
  - `training/orchestration/*.py` (여러 파일)

### 7. core/orchestration, core/mcp 폴더 제거
- 모든 파일 삭제 완료
- 외부 참조 없음 확인 완료

---

## 새로운 구조

```
app/domain/v1/minso/hub/
├── decision_maker.py          # 정책/규칙 판단 (KoELECTRA)
├── orchestrators/

│   └── reasoning_orchestrator.py  # 정책 처리 (기존 유지)

    ├── message.py
    └── transport.py
```

## 확인 사항

### MinsoHub._handle_rule의 action_mapping
현재 `action_mapping`에 정의된 액션:
- `training`: `create_training_data` → `create`
- `submission`: `create_text_answer`, `create_image_answer` → 그대로
- `reasoning`: `create_task` → 그대로

**주의**: API에서 호출하는 모든 액션이 `action_mapping`에 정의되어 있지 않으면, 기본적으로 `action` 이름 그대로 서비스 메서드를 찾습니다.
→ **필요 시 action_mapping 확장 필요.**
